# Prospecta Campinas

Dashboard de prospecção local em português do Brasil, com uma lista inicial de dez clínicas de fisioterapia pesquisadas em Campinas.

## Desenvolvimento

- `pnpm install`
- `pnpm dev`
- `pnpm build`

O CRM é armazenado em `localStorage` no navegador. Os contatos listados são públicos e as oportunidades de serviço são hipóteses não validadas. O app não envia mensagens, processa pagamentos, cria agendamentos externos nem publica conteúdo. Os módulos sem integração real são identificados como demonstração ou “Em breve”.
